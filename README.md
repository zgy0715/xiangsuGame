# 像素填空 (Fill-a-Pix)

> 逻辑与像素的碰撞 —— 一款基于数字线索推理的 Android 像素画解谜游戏

Fill-a-Pix（像素填空）是一种经典逻辑谜题：棋盘上的每个数字提示告诉你在它周围 3×3 区域内需要涂黑的格子数量，玩家通过逻辑推理确定每个格子的状态，最终拼出一幅完整的像素画。

本项目使用 **Kotlin + Jetpack Compose** 实现，逻辑层与 UI 层完全分离，核心算法（提示推导、唯一解校验、矛盾检测）可独立进行单元测试。

## ✨ 功能特性

- **三态方格**：未确定 / 涂黑 / 标记空白，单击循环切换
- **长按快捷操作**：长按直接标记为空白
- **撤销 / 重做 / 重置**：基于指令栈的标准操作历史
- **错误提示**：实时"确定性矛盾检测"，只标红必错的格子，不误报中间态（可开关）
- **计时挑战**：通关计时 + 结算弹窗
- **关卡制**：6 关由易到难 —— 简单 10×10（红心 / 笑脸）、中等 20×20（小房子 / 小鱼）、困难 35×35（星星 / 皇冠）
- **顺序解锁 + 存档**：通关第 N 关解锁第 N+1 关，进度本地保存，重启保留
- **参考答案**：随时查看完整像素画，看过会在结算中标注
- **通关揭晓**：通关后棋盘直接呈现干净完整的像素画
